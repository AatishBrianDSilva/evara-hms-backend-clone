Download OpenAPI specification:Download

Ratandeep Arunkumar: ratandeep@growthverse.in URL: https://www.growthverse.in License: Apache 2.0

Comprehensive APIs for the HMS (Health Management System) focused on fertility treatments and IVF procedures. This API requires JWT authentication for all endpoints. Access to specific operations is based on user roles, including Admin, Doctor, and Patient roles.

Appointment

APIs for scheduling, updating, and canceling appointments.
